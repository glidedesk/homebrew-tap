# GlideDesk Homebrew Tap

Official Homebrew tap for [GlideDesk](https://github.com/glidedesk/GlideDesk) — lightweight, zero-latency multi-device KVM & seamless workspace bridge.

## Installation

```bash
brew install --cask glidedesk/tap/glidedesk
```

Or add the tap first:

```bash
brew tap glidedesk/tap
brew install --cask glidedesk
```

## Update

```bash
brew update
brew upgrade --cask glidedesk
```
